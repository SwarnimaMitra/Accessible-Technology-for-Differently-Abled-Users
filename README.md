# Accessible Technology for Differently-Abled Users

## 🌟 Project Overview

Accessible Technology for Differently-Abled Users is an AI-powered accessibility platform designed to empower people with disabilities through intelligent assistive technologies. The platform integrates multiple accessibility solutions into a single mobile-friendly web application, enabling users to communicate, navigate, and access digital content more independently.

The system is specifically designed for the approximately 26 million differently-abled individuals in India who often lack affordable and accessible technological support. The platform is optimized for low-cost Android devices and integrates with popular applications such as WhatsApp and Gmail for seamless communication.

---

## 🎯 Objectives

* Improve communication for hearing and speech-impaired users.
* Assist visually impaired users in understanding their surroundings.
* Simplify digital content for individuals with learning disabilities.
* Provide affordable and accessible AI-powered solutions.
* Promote digital inclusion and independence.

---

## 🚀 Key Features

### 🤟 Real-Time Sign Language Recognition

* Recognizes Indian Sign Language (ISL) gestures using a smartphone camera.
* Converts sign language into text and speech in real time.
* Enables smooth communication between deaf and hearing individuals.

### 👁️ Scene Description for Visually Impaired Users

* Uses the device camera to capture surroundings.
* Generates detailed audio descriptions of nearby objects, people, and environments.
* Helps users navigate unfamiliar places independently.

### 🎤 Speech-to-Text for Speech Impairments

* Converts spoken words into text.
* Uses custom acoustic models trained to better understand speech variations and impediments.
* Improves communication accessibility.

### 📚 Text Simplification Engine

* Converts complex text into easier-to-understand language.
* Assists users with dyslexia, cognitive disabilities, and learning difficulties.
* Enhances reading comprehension.

### 📱 App Integration

* WhatsApp message creation and sharing.
* Gmail email drafting assistance.
* Easy communication through commonly used applications.
